1. Understanding Decision Theory

Decision theory helps businesses choose the best alternative when the future is uncertain.

Important concepts

  • Alternative: A possible decision a company can make.
  • State of Nature: An external event that cannot be controlled.
  • Payoff: The financial result of a decision.
  • Probability: The likelihood of an event occurring.

Decision Criteria

Maximax: Select the alternative with the highest possible payoff.
Maximin: Select the alternative with the highest minimum payoff.
Minimax Regret: Select the alternative with the lowest maximum regret.
EMV / Bayes: Select the alternative with the highest expected monetary value.
